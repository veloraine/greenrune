# Not in scope

Every "wouldn't it be cool if..." idea goes here, NOT into the code.
The presence of an idea here means it will be considered AFTER the current phase ships, not before.

## Deferred to Phase 4+ (combat era)

- Combat (any kind)
- Weapons and weapon mastery
- Magic and spells
- Dungeons and dungeon generation
- Monsters and monster taming
- Boss fights
- Crafting / forging (with stat inheritance — needs combat to matter)

## Deferred to Phase 2+ (after farm prototype is solid)

- Town scene
- NPCs (Phase 1 sells through the shipping bin; RF4 shops buy nothing)
- Dialogue system (Dialogic 2 integration)
- Friendship / affection system
- Gift system
- Context-sensitive dialogue line selection

## Deferred to Phase 3+ (after town is solid)

- Seasons (currently only Spring exists)
- Festivals
- Weather beyond clear / sunny
- Calendar UI
- Cooking
- Orders menu / town points (unlock shops, festivals, farm expansion)

## Deferred indefinitely (consider only post-vertical-slice)

- Marriage / romance
- Children
- Fishing
- Mining
- Foraging
- Chemistry (medicine)
- Soil hidden stats, giant crops
- More than ~6 skills (RF4 has 38)
- Minigame festivals (exhibition-style festivals come first)
- Online multiplayer
- Mod support
- Console / Switch port

## Asset-related deferrals

- Custom humanoid modeling (use KayKit retextures instead)
- Custom building modeling (use Quaternius / KayKit Dungeon)
- Custom rigging (use Mixamo)
- Original music (use CC0 packs until Phase 4+)

## How to add to this list

When a "wouldn't it be cool" thought hits:

1. Write it here with the date.
2. Note which phase it would fit in (or "indefinite").
3. Close the editor and step away.
4. Do NOT open the project to start coding it.
