# Greenrune

A Rune Factory 4-inspired farming and town life sim. This glossary covers the language of its characters.

## Characters

**Base body**:
The one shared character body every person in the game is built on, made by us on the KayKit Adventurers skeleton.
_Avoid_: base model, rig, KayKit body

**Body type**:
A variant of the base body with its own proportions: adult, child or elderly. All body types share one skeleton.
_Avoid_: model type, age model

**Character part**:
A swappable piece added to a base body to make a specific person: head, hair, outfit or accessory.
_Avoid_: attachment, slot item

**Stand-in character**:
The first complete character on the base body, built by Claude to match the benchmark model as closely as possible, and used in the game until the user builds their own.
_Avoid_: temp model, placeholder, dummy

**Benchmark model**:
The reference character we measure our base body against for proportions, face and eyes. It is studied, never copied into the game.
_Avoid_: baseline, template, sample model
