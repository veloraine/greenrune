# Phase 10 — Polish & launch (M3)

**Goal:** Greenrune 1.0 is balanced, readable, bug-free on the main paths, and released.
**Estimate:** 3–4 months (~13–17 weeks).
**Starts when:** [Phase 9](phase-09-story-late-game.md) is done.
**Background:** [research › Criticism](../rf4-research.md#criticism-from-critics-and-players) (UI, tutorial, event bugs).

Every checked item must meet the [definition of done](../endgame.md#definition-of-done).

## Step 1 — Balance pass (weeks 1–3)

- [ ] Script that exports all data resources to CSV for review
- [ ] Check curves: RP costs vs refills, skill XP, prices, drop rates, taming odds
- [ ] Fix outliers in data, not code

**Done when:** every curve has been reviewed in the CSV and outliers fixed.

## Step 2 — UI and controls (weeks 4–6)

- [ ] Controller support in every menu
- [ ] Remappable keys
- [ ] Text-size option; readable at 1080p from 2 m (TV test)
- [ ] Every menu reachable in ≤2 screens

**Done when:** a full in-game day can be played with only a controller, on a TV, without squinting.

## Step 3 — Audio (weeks 7–8)

- [ ] Music per season and per area (CC0 or commissioned)
- [ ] Audit list: every player action has a sound

**Done when:** the audit list has no action without a sound.

## Step 4 — Bugs, events, saves (weeks 9–10)

- [ ] Event audit: every event has a guaranteed trigger path; no soft-locks
- [ ] Keep one save from every save version (v1–v9) in a test folder
- [ ] Every old save loads into the final version

**Done when:** all old saves load, and no known progression blocker remains.

## Step 5 — First-hour pass (week 11)

- [ ] 3 new players play the first hour
- [ ] Fix the top confusion points

**Done when:** all 3 reach every core system in the first 2 hours without help.

## Step 6 — Launch (weeks 12–17)

- [ ] Windows and macOS builds tested on other machines
- [ ] Trailer and store page
- [ ] Launch-day checklist: builds uploaded, page live, known-issues list
- [ ] Post-launch patch plan (first 2 weeks)

**Done when:** 1.0 is public.

## Phase done when (Greenrune 1.0)

- [ ] 1.0 is downloadable on Windows and macOS
- [ ] No known progression blockers
- [ ] Saves from every version load
- [ ] Playable with a controller on a TV
- [ ] Everything in the [1.0 scope table](../endgame.md#scope-targets) is in the game
