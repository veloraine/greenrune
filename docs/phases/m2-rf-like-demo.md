# Milestone M2 — RF-like demo

**Goal:** a public demo that proves Greenrune is an RF-like: farming, combat, taming, forging and a dungeon feeding each other.
**Estimate:** ~1 month (~4–5 weeks).
**Starts when:** [Phase 7](phase-07-dungeons.md) is done.

Every checked item must meet the [definition of done](../endgame.md#definition-of-done).

## Step 1 — Demo cut (week 1)

- [ ] Demo covers Spring and Summer, with Dungeon 1 and Boss 1
- [ ] End card on Summer 30
- [ ] Demo saves stay compatible with the full game

**Done when:** a new demo game reaches the end card on Summer 30.

## Step 2 — Performance (week 2)

- [ ] Pick a low-end target machine (e.g. a laptop with integrated graphics)
- [ ] Profile the town on festival day and the field with 10 monsters
- [ ] Fix the top costs (draw calls, lights, AI updates)

**Done when:** a steady 60 fps on the target machine in both scenes.

## Step 3 — Feel playtest (week 3)

- [ ] 5 testers play the demo
- [ ] Ask each: "Which felt worse, farming or combat?"
- [ ] Fix feel issues before any new content

**Done when:** most testers rate combat and farming equally good.

## Step 4 — Public page (weeks 4–5)

- [ ] Store page (itch.io, or Steam if you have a Steamworks account)
- [ ] Short trailer or GIFs showing the farm → fight → tame → craft loop
- [ ] Feedback channel (comments or a form)

**Done when:** the demo is public.

## Milestone done when

- [ ] Demo is downloadable
- [ ] 60 fps on the low-end target
- [ ] Feedback triaged into a list, with feel fixes ranked first
