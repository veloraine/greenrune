# Milestone M1 — Cozy slice

**Goal:** ship Phases 1–3 as a finished free game on itch.io, labelled honestly as a cozy farm-and-town sim. If the project stops here, you have still shipped a game.

**M1 is complete when:**
- The slice is downloadable on itch.io and runs on Windows and macOS machines that aren't yours.
- 3 testers who haven't seen the game till, plant, water, ship and talk to an NPC on day 1 without asking you anything.
- The continue/stop decision is written in plan.md, with the reason.

**Starts when:** [Phase 3](phase-03-seasons-cooking-orders.md) is done. This is the decision point after Phase 3 in [plan.md](../plan.md#phase-35--stop-and-re-evaluate).

**Steps:**
1. **Content top-up.** 2–3 more NPCs with schedule, tastes, birthday and ~50 lines each; final portraits for every NPC in the style set in [Phase 2.0](phase-02-town-npcs.md#phase-20--character-base). A new child or elderly NPC gets its body here if it is the first of its kind, on the same skeleton.
2. **First hour.** Builds on [Phase 1.5](phase-01-farm-loop.md#phase-15--the-days-frame)'s first-morning lesson and [Phase 2.4](phase-02-town-npcs.md#phase-24--request-box)'s request box. A skippable intro under 2 minutes; first-time hints for till, plant, water, ship, talk and sleep; no system locked behind a long guided sequence.
3. **Game shell.** A title screen (New, Continue, Options, Quit); Options for volume, fullscreen and text size (the UI scale RF4 Special lacked); credits listing every asset pack and its license.
4. **Builds and playtest.** Windows and macOS exports; 3 people who haven't seen the game play the first hour while you watch silently; fix the top 5 confusion points.
5. **Release and decide.** An itch.io page with screenshots, a GIF and the description "cozy farm-and-town sim", free; write the decision in [plan.md](../plan.md): stop, start a new project, or continue to [Phase 4](phase-04-combat-core.md).

**Checklist:**
- [ ] 5–8 NPCs each have a final portrait and a full line set
- [ ] The intro takes under 2 minutes and can be skipped
- [ ] Each first-time hint shows once and never again, also after a load
- [ ] The game starts, saves and quits only through its own menus, and Options changes volume, fullscreen and text size
- [ ] The credits list every asset pack and its license
- [ ] The itch.io page is public with screenshots, a GIF and the "cozy farm-and-town sim" label

**Out of scope for this milestone:** new systems; combat, dungeons and taming (Phase 4+).

**Reference:** RF4's first-hour shape ([RF4 and Farnia research › Game plan](../rf4-farnia-research.md#1-game-plan-how-rf4-paces-its-opening)); Special's HUD criticism ([› Design](../rf4-farnia-research.md#3-design-art-direction-ui-and-feedback)).
