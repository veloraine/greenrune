# Milestone M1 — Cozy slice

**Goal:** ship Phases 1–3 as a finished free game on itch.io, labelled honestly as a cozy farm-and-town sim. If the project stops here, you have still shipped a game.
**Estimate:** 1–2 months (~4–9 weeks).
**Starts when:** [Phase 3](phase-03-seasons-cooking-orders.md) is done. This is Phase 3.5 in [plan.md](../plan.md#phase-35--stop-and-re-evaluate).

Every checked item must meet the [definition of done](../endgame.md#definition-of-done).

## Step 1 — Content top-up (weeks 1–3)

- [ ] 2–3 more NPCs: schedule, tastes, birthday, ~50 lines each
- [ ] Final portraits for every NPC in one consistent style

**Done when:** 5–8 NPCs, all with final portraits and full line sets.

## Step 2 — First hour (weeks 4–5)

- [ ] Intro under 2 minutes, skippable
- [ ] First-time hints for till, plant, water, ship, talk, sleep (each shown once)
- [ ] No system locked behind a long guided sequence

**Done when:** a new player tills, plants, waters, ships and talks to an NPC on day 1 without asking you anything.

## Step 3 — Game shell (week 6)

- [ ] Title screen: New, Continue, Options, Quit
- [ ] Options: volume, fullscreen, text size
- [ ] Credits listing every asset pack and its license

**Done when:** the game starts, saves and quits only through its own menus.

## Step 4 — Builds and playtest (weeks 7–8)

- [ ] Windows and macOS exports run on a machine that isn't yours
- [ ] 3 people who haven't seen the game play the first hour while you watch silently
- [ ] Fix the top 5 confusion points

**Done when:** all 3 testers get through day 1 without help after the fixes.

## Step 5 — Release and decide (week 9)

- [ ] itch.io page: screenshots, a GIF, description ("cozy farm-and-town sim"), free
- [ ] Write the decision in [plan.md](../plan.md): stop, start a new project, or continue to [Phase 4](phase-04-combat-core.md)

**Done when:** the page is public and the decision is written down.

## Milestone done when

- [ ] Greenrune slice is downloadable on itch.io
- [ ] It runs on Windows and macOS
- [ ] 3 testers finished day 1 unaided
- [ ] The continue/stop decision is recorded, with the reason
